# 📚 Document Research Assistant

An AI-powered Document Research Assistant built with **Streamlit**, **LangChain (LCEL)**, and **Google Gemini 2.5 Flash**. This application leverages **Retrieval-Augmented Generation (RAG)** to analyze multiple academic papers providing precise answers with source citations.

---

## 🚀 Features

- **Multi-PDF Processing:** Upload and analyze multiple PDF documents simultaneously.
- **Context-Aware Chat:** Remembers conversation history for seamless follow-up questions.
- **Local Embedding Vector Search:** Powered by HuggingFace `all-MiniLM-L6-v2` and ChromaDB for zero-cost semantic search.
- **Source Citations:** Every answer includes exact document sources and page numbers for transparency.
